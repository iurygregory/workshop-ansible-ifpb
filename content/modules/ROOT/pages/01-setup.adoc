= Preparando o Ambiente

Antes de começar, precisamos garantir que o ambiente esta pronto.

== Pré-requisitos

* Acesso SSH da VM 1 (control node) para a VM 2 (managed node)
* CentOS Stream 10 em ambas as VMs

== Instalando o Ansible na VM 1

Conecte-se na VM 1 e execute:

[source,bash]
----
sudo dnf install -y ansible-core
----

Verifique a instalação:

[source,bash]
----
ansible --version
----

== Clonando o Repositorio

[source,bash]
----
git clone https://github.com/iurygregory/workshop-ansible-ifpb.git
cd workshop-ansible-ifpb
----


== Testando a Conectividade

Verifique se a VM 1 consegue acessar a VM 2:

[source,bash]
----
ping <IP_DA_VM2>
----

Teste o acesso SSH:

[source,bash]
----
ssh <usuario>@<IP_DA_VM2>
----

[TIP]
====
Para saber os IPs de cada máquina virtual utilize o comando abaixo:

[source,bash]
----
ip -c a
----
====
