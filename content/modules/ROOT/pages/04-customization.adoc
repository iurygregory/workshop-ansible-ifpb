= Personalizando o nginx

Agora vem a parte divertida! Vamos alterar a versão e a porta do Nginx e observar como a página web muda.

== Cenario 1: Porta Padrão (80) + Versão Padrão

Este é o estado inicial. A pagina mostra a imagem `default.png`.

[source,bash]
----
ansible-playbook playbooks/site.yml
----

Acesse: `http://<IP_DA_VM2>:80`

Resultado esperado: imagem padrão.

== Cenario 2: Porta Customizada + Versão Padrao

Mude a porta para 8080:

[source,bash]
----
ansible-playbook playbooks/site.yml -e nginx_port=8080
----

Acesse: `http://<IP_DA_VM2>:8080`

Resultado esperado: mensagem de aviso pedindo para instalar a versão mais recente do nginx.

[NOTE]
====
O playbook configura automaticamente o SELinux e o firewall para permitir a nova porta.
====

== Cenario 3: Porta Customizada + Versão Mais Recente

Agora ative o repositorio oficial do nginx.org e use uma porta customizada:

[source,bash]
----
ansible-playbook playbooks/site.yml -e nginx_enable_official_repo=true -e nginx_port=8080
----

Acesse: `http://<IP_DA_VM2>:8080`

Resultado esperado: mensagem de parabéns com a imagem `latest.png`.

== Desafio

Tente as seguintes combinacoes e observe o resultado:

1. Volte para a porta padrão mantendo o repositório oficial
2. Use a porta 9090 sem o repositório oficial
3. Use a porta 443 com o repositório oficial

[TIP]
====
Voce pode editar as variáveis diretamente no arquivo `inventory/group_vars/webservers.yml` em vez de passar pela linha de comando com `-e`.
====
