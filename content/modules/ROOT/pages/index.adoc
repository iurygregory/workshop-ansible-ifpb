= Workshop - Ansible na prática: O simples que resolve

Bem-vindo ao workshop de Ansible do IFPB! Neste workshop voce vai aprender a usar o Ansible para automatizar a instalação e configuração do nginx em uma máquina virtual CentOS Stream 10.

== O Que Este Workshop Cobre

* Conceitos básicos de Ansible (inventario, playbooks, roles)
* Instalação e configuração do Nginx via Ansible
* Controle de versão do Nginx (repositório padrão vs. oficial)
* Configuração de porta customizada
* Interação com firewalld e SELinux
* Verificação automática de acessibilidade

== Para Quem é Este Workshop ?

Estudantes que desejam aprender automação de infraestrutura com Ansible. Não é necessário conhecimento prévio de Ansible.
